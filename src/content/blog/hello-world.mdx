## Welcome

This is my first blog post! I built this portfolio using some amazing technologies:

- **Next.js** for the framework
- **React Three Fiber** for 3D rendering
- **GSAP** for scroll-driven animations
- **MDX** for this very blog

## The Tech Stack

The entire site is built with a comic book aesthetic inspired by Spider-Verse. Every panel, every animation, every glitch effect is designed to make you feel like you're reading a living comic book.

### 3D Models

The Spider-Man and Manhattan models are rendered in real-time using WebGL through React Three Fiber. The parallax effect on the cityscape creates depth as you scroll.
